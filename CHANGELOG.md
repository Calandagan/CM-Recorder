# Changelog

## 0.3.0 — preliminary Global release

- Standalone Windows x64 recorder for Room Match, CM groups/finals and Practice.
- Local capture setup/removal and read-only reuse of approved compatible capture.
- Race inspector, course statistics, skill categories/icons and character portraits.
- Mihono Studios neutral/coral visual design with dark and light themes.
- Skill activation consistency: minimum sample, own/all runners, optional green
  passives, missing-activation filters and conservative static catalog explanations.
- Structured recording exports with optional verified matching raw replay data.
- Proprietary free-use license, community attribution and preserved third-party notices.

Validation: 70 source tests and synthetic encrypted-recording/export self-test;
compiled self-test, relocated execution, offline HTTP lifecycle and capture
install/remove checks against a fictitious game directory. No actual game files
were modified by those checks. Clean-PC and full live-game acceptance of this
exact package remain unverified; published as a pre-release.
