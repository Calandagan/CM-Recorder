# Support

Report bugs through [GitHub Issues](https://github.com/Calandagan/CM-Recorder/issues/new/choose).

Include the release version/build, Windows version, supported race mode,
installation/receiver status, expected behavior and reproduction steps. State
whether it also happens offline and whether a row/raw replay was recorded.
Screenshots and exported samples are optional; review them first.

Do not post credentials, tokens, private salts, installation receipts, full local
data/session folders or unreviewed recordings. Replace personal Windows paths
with `%LOCALAPPDATA%` when reporting them. For a potential security issue, do not
publish secrets or other people's information in an issue; start with a non-sensitive
description so an appropriate private exchange can be arranged.

Feature requests should describe the task and desired outcome. JP, DMM, bot input,
animation acceleration and source-code distribution are outside this release's scope.
